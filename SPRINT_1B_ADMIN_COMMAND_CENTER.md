# Sprint 1B — Admin Command Center

Implemented a business-first admin dashboard using live Prisma data.

## Added
- Today's priorities: operations, agent approvals, custom requests, draft quotes, support
- Business health KPIs: gross booking value, collected, outstanding, travelers
- Booking and expense status mini-KPIs
- Upcoming departures with capacity visualization
- Quick actions
- Recent booking activity
- Responsive desktop/mobile layout
- Epoch Journeys navy/dark-red visual language

No Prisma schema migration is required for this sprint.
